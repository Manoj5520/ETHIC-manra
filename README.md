# ETHIC × MANRA — Strategic Reference

A standalone, responsive website documenting ETHIC's evolution toward **Behavior Engineering**, MANRA's discovery and qualification method, early gadget concepts, the F1–F5 friction board, P1/P2 qualification, prototype-budget assumptions, and the current decision point.

## Public site

- **Source repository:** https://github.com/Manoj5520/ETHIC-manra
- **GitHub Pages URL (after the deployment workflow succeeds):** https://manoj5520.github.io/ETHIC-manra/

## Structure

- `index.html` — complete single-page website, custom diagram visuals, responsive navigation and the Polygons applied case study.
- `assets/favicon.svg` — ETHIC-inspired gold fingerprint favicon.
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow.
- `netlify.toml` — optional static publishing configuration if this repository is also imported into Netlify.
- `.nojekyll` — prevents Jekyll processing.

The website uses self-contained HTML/CSS/SVG visuals. The Polygons product reference uses a publisher-linked YouTube embed instead of re-hosting third-party television footage.

## Strategic status: current, not aspirational

- **ETHIC:** intended category — Behavior Engineering Company. Affordable, portable everyday physical products are the current commercial vehicle being explored; they are not the full definition of the company.
- **MANRA:** strategic intelligence, behaviour-led discovery, qualification and growth system behind ETHIC.
- **F1 / Force-Induced Migration:** leading current candidate; not cleared as P1 and not a validated product.
- **P1:** not cleared / unclaimed.
- **P2:** unclaimed.
- **Prototype target:** ₹11,500–₹12,500 (broader planning envelope approximately ₹11,000–₹13,000), not spend incurred, secured funding or a production budget.
- **Historical gadget price points:** SOS keychain ₹599, emergency watch ₹1,299, torch/powerbank/SOS ₹799 and smart pen ₹499 are early ideation targets only, not validated retail prices or unit economics.
- TPU printing, silicone casting and NdFeB magnets are possible methods/materials to evaluate if justified by the design question, not a selected bill of materials.
- Kurnool, Hyderabad/T-Works, Hosur and Bengaluru are possible sourcing/prototyping search areas, not confirmed suppliers or partnerships.
- Validation KPIs and the 90-day sequence are targets/planning aids, not achieved results or a committed schedule.

## Applied case study — Polygons Design

The case study follows the MANRA method section and precedes ETHIC's F1 worked example. It illustrates an external product-design precedent: two fold-flat tools cover six measuring sizes and compact for storage. It is **not an ETHIC product**, not evidence that ETHIC's thesis is validated, and not automatically a template to copy.

The supplied Shark Tank clip was reviewed for its mechanism and claims. The public page embeds a publisher-linked product video instead of re-hosting the television segment. Metrics mentioned in third-party reporting are treated as reported claims—not audited financial statements, proof of profit, or ETHIC results.

## Evidence discipline

- Observed does not automatically mean validated.
- A workaround indicates behaviour to investigate; it does not prove commercial demand.
- A candidate is not a cleared P1.
- A cleared P1 is not automatically a validated product.
- Validation is not the same as scalable unit economics.
- Do not describe an IP position, partnership, prototype, sale or KPI as achieved unless the relevant evidence exists.

## Publication caution

This is a public repository. Candidate logic, budget assumptions, early price hypotheses and technical hypotheses are visible to anyone. Before disclosing a potentially novel implementation in detail, consider a confidential IP review. This page is not a patentability opinion or freedom-to-operate review.

## Deployment

The GitHub Actions workflow under `.github/workflows/pages.yml` attempts to configure GitHub Pages and deploy the repository root on every push to `main`. After the workflow reports success, open **Settings → Pages** or the workflow summary to verify the canonical published URL.

No build command is required. If importing the repository into Netlify as a separate deployment, use the repository root as the publish directory.
